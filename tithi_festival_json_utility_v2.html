Tithi Festival JSON Utility

Upload the CSV exported from your Google Sheet. The utility converts each festival row into the two formats used by your project.

Expected columns: Month, Month index, Tithi, Tithi index, Festival Name (Key), English

1. TITHI_FESTIVALS

This is JavaScript rather than strict JSON because it includes the const TITHI_FESTIVALS = declaration.

2. festivals blob for en.json

This is the object you can place inside the "festivals" property of your en.json file.
