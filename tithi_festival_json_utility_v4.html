Tithi Festival JSON Utility

Upload the CSV exported from your Google Sheet. The utility converts each festival row into the three formats used by your project.

Expected columns: Month, Month index, Tithi, Tithi index, Festival Name (Key), English, Gujarati

1. TITHI_FESTIVALS

This outputs only the array contents. Paste it inside your existing const TITHI_FESTIVALS = [].

2. festivals blob for en.json

This is the object you can place inside the "festivals" property of your en.json file.

3. festivals blob for gu.json

Uses the same festival keys as en.json and the Gujarati values from your CSV's Gujarati column.
